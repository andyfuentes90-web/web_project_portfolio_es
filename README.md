# Portafolio Profesional de Desarrollo Web Full Stack

Este proyecto fue desarrollado como parte de un ejercicio práctico para aplicar conocimientos de desarrollo web. Su objetivo es ofrecer una solución funcional e intuitiva, implementando tecnologías como HTML y CSS para crear una experiencia de usuario eficiente y accesible.

## 🚀 Demo
Puedes ver el proyecto publicado en GitHub Pages aquí:
👉 https://TU-USUARIO.github.io/TU-REPOSITORIO/

## 📋 Características
- Diseño web responsivo adaptable a diferentes dispositivos.
- Interfaz intuitiva y fácil de usar.
- Navegación clara y organizada.
- Implementación de estilos modernos con CSS.
-- Código estructurado y fácil de mantener.
- Compatible con los principales navegadores web.
- Publicación y acceso en línea mediante GitHub Pages.

## 🛠️ Tecnologías utilizadas
 
- **HTML5**: Estructuración y organización del contenido de la página web.
- **CSS3**: Diseño visual, estilos y adaptación a diferentes dispositivos.
- **JavaScript**: Implementación de funcionalidades interactivas y manipulación dinámica del contenido.
- **Git**: Control de versiones y seguimiento de cambios en el proyecto.
- **GitHub**: Almacenamiento, gestión y colaboración del repositorio.
- **GitHub Pages**: Despliegue y publicación del proyecto en línea.

## 📁 Estructura del proyecto

```text
web_project_portfolio_es/

├── assets/
│ ├── fonts/ # Archivos .woff y .woff2 (Open Sans, Archivo Black)
│ └── images/ # Fotografías e imágenes optimizadas
├── blocks/ # Archivos CSS organizados con metodología BEM
│ ├── page.css
│ ├── header.css
│ ├── profile.css
│ ├── project.css
│ └── ...
├── pages/
│ └── index.css # Importación de estilos y definición de fuentes
├── vendor/
│ └── normalize.css # Normalización de estilos entre navegadores
├── index.html # Página principal del portafolio
└── README.md # Documentación del proyecto
```
