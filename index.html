Proyectos Destacados

Pagina web de una Cafetería

Página web responsiva de una cafetería, desarrollada desde cero utilizando HTML5 y CSS3 a partir de un Brief de diseño. Para su maquetación se implementaron la metodología BEM, Flexbox y CSS Grid, asegurando un código limpio, modular, mantenible y escalable. El proyecto incluye un menú de navegación intuitivo y un formulario de contacto funcional, y se encuentra publicado para su visualización en GitHub Pages.

Tarjeta Presentación Web

Este sitio web de portafolio personal es una tarjeta de presentación digital profesional con diseño totalmente responsivo, desarrollada a partir de un prototipo en Figma con maquetación semántica en HTML5 y CSS3 bajo la metodología BEM. Incorpora adaptabilidad fluida para pantallas móviles, tabletas y escritorio (desde 320px hasta más de 1440px) usando Flexbox, CSS Grid y Media Queries; rendimiento optimizado con fuentes locales (.woff/.woff2) y compresión de assets; y efectos visuales avanzados como luces de fondo mediante radial-gradient con calc(), velos oscurecidos con linear-gradient y tarjetas de proyectos en proporción aspect-ratio: 16/9, todo alojado y desplegado de forma pública en GitHub Pages.
